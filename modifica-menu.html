Collegamento

Per salvare serve la chiave di accesso del sito (si inserisce una volta sola su questo telefono o computer). Senza chiave puoi guardare e provare le modifiche, ma non pubblicarle.

Come si crea la chiave
  1. Su GitHub apri Nuova chiave (fine-grained token).
  2. In Repository access scegli Only select repositories e seleziona solo il repository del sito.
  3. In Permissions → Contents scegli Read and write. Nient'altro.
  4. Crea la chiave, copiala e incollala qui sopra.
